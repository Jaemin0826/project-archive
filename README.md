# 프로젝트 더미 — TV 아카이브 목업

프로젝트 더미(PROJECT DUMMi)는 개인 작업을 TV 벽에 쌓아 두는 아카이빙 서비스 목업입니다. 빌드 없이 `index.html`을 열면 됩니다.

## 여는 방법

로컬에서 정적 서버를 켜거나 `index.html`을 브라우저로 엽니다.

```bash
python3 -m http.server 8765
```

그다음 http://localhost:8765 로 접속합니다.

## 편집 암호

보는 것은 누구나 할 수 있습니다. 아래 동작을 처음 할 때만 암호를 묻습니다.

- 새 프로젝트(`+` TV), 업데이트 송출(ON AIR)
- TV 위치 옮기기, 카테고리 추가/삭제
- 방송 종료, 이름 변경, 비공개 전환, 창고로 보내기/되돌리기
- 샘플 데이터로 되돌리기

목업 암호는 `0000` 입니다. 한 번 맞추면 이 브라우저의 localStorage에 기억됩니다.

비공개 프로젝트와 비공개 업데이트는 암호를 넣기 전에는 파란 `NO SIGNAL` 화면으로만 보입니다.

## 조작

- 빈 배경을 드래그하거나 트랙패드/휠로 TV 벽을 이동합니다.
- `Ctrl` + 휠, 또는 오른쪽 아래 `+` `−`로 확대/축소합니다.
- TV를 드래그하면 칸에 붙고, 겹치는 TV는 밀려납니다.
- 검색창에서 프로젝트를 고르면 그 TV로 날아갑니다.
- 카테고리 칩을 고르면 다른 TV가 어두워집니다.
- `⌂` 버튼은 가장 최근에 업데이트한 TV로 돌아갑니다.
- `창고`에는 지운 프로젝트가 30일 동안 남아 있습니다.

샘플 카테고리는 전체 · 이미지 · 영상 · 3D · 사갈 입니다. 카테고리는 추가하거나 지울 수 있습니다.

데이터가 꼬이면 오른쪽 위 `···` → **샘플 데이터로 되돌리기**를 누르면 됩니다. 기준 날짜는 기획 시점인 **2026-11-07**로 고정되어 있어서, TV의 ON AIR / 꺼짐 상태가 바뀌지 않습니다.

## 구성

- `index.html` — 화면 뼈대
- `style.css` — TV·벽·인벤토리·RECAP 스타일
- `data.js` — 샘플 프로젝트 12개
- `app.js` — 동작 (localStorage 키 `tv-archive-data`, `tv-archive-unlocked`)
- `images/th-01.jpg` … `th-15.jpg` — 썸네일

3D 파일은 줌인했을 때 Three.js(CDN)로 큐브를 돌리고 줌할 수 있습니다. CDN이 막히면 `Three.js 예정`이라고만 보여 줍니다.
